The UI system combines a rendering pipeline with a layout foundation for interface elements. Its development also covers interactive controls, including button states, slider fill behavior, and gamepad navigation.

## Rendering and layout

UI elements are submitted through a dedicated rendering pass. Canvas render modes and the Transform2D layout system provide the basis for arranging interface elements in the engine.
