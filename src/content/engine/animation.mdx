The engine’s animation work spans runtime playback, character skinning, and state-driven transitions. The state machine tool provides a graph-based workflow for creating states and connecting transitions.

## Runtime and authoring

Animation clips can be imported and played through the runtime system. State machines build on that foundation by describing how animation states change in response to triggers, while the visual editor supports creating and editing those graphs.
