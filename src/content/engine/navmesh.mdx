The navigation system uses a baked NavMesh as the basis for pathfinding. Custom areas and agent profiles allow different characters to follow different traversal rules over the same navigation data.

## Areas and traversal filters

Modifier volumes assign area types during baking. At runtime, polygon flags and query filters determine which areas an agent can use. The project’s navigation profiles connect those traversal rules to gameplay behavior.
