The asset system manages the path from source files to resources used by the engine. Its responsibilities include scanning files, importing supported formats, tracking metadata, and loading processed assets when they are needed.

## Import and identity

The import pipeline converts source assets into engine-friendly data and tracks asset identity and dependencies through metadata. Processed data is stored separately from source files, while the index connects asset identifiers to their metadata.

## Loading and caching

The runtime load path checks cached resources before loading processed data. This keeps asset discovery, import, and runtime access as distinct parts of the system.
